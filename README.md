# MetaCentrum Workshop

Running R on shared Czech academic computers.

For people who know R and statistics, and have not used a cluster.

## Start here

On MetaCentrum, in a terminal or in OnDemand's terminal:

```bash
curl -sL https://raw.githubusercontent.com/ChlupacTheBosmer/metacentrum-workshop/main/bootstrap.sh | bash
```

That puts everything in `/storage/plzen1/home/<username>/metacentrum-workshop`,
the same place for everybody, and makes a `results/` folder of your own.

Participants: also read [setup.md](setup.md) before the day.

## The project

One study runs through the whole day:

> Does the text of a product review carry its star rating, and does that
> relationship differ between product categories?

Real reviews cannot be scraped in a morning, so a language model writes
them from a rating we choose. Because we choose it, we know the right
answer, which is what makes it a simulation study rather than a demo.

There is also a control arm with the ratings shuffled, where a correct
method must find nothing.

## Rules of the repository

- **Nothing infrastructure specific is hardcoded.** URLs, module names,
  queue names, storage paths and model names live in `config.R` only
- **No keys, anywhere.** They come from `$EINFRA_API_KEY`. Run
  `tools/check_secrets.sh` before committing
- **Code is written to be read.** Plain language comments, no dense one
  liners where several clear lines would do

## Language

maintaining two versions.
